# Security policy

## Supported versions

Only the `main` branch of this repository is actively maintained. There are **no** security-supported
release builds distributed from this GitHub project.

## Reporting a vulnerability

If you believe you have found a security issue in **project-specific** code (build scripts, Android
Java shell, local tooling):

1. **Do not** open a public issue for exploitation-ready vulnerabilities.
2. Open a **private** security advisory on GitHub (Security → Advisories → New draft) or contact the
   repository owner through GitHub.

Please include reproduction steps and affected paths. Game-data or third-party SDK issues may need to
be routed upstream (ReXGlue, SDL, etc.).

## Out of scope

- Circumvention of commercial game DRM or piracy facilitation
- Commits or issues that include copyrighted Xbox 360 game binaries or assets
- General emulator malware; this project is not an attack surface against remote users by default
